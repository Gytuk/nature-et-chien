# Modèles des fichiers de travail

Fichiers dans `_briefs/<slug>/`. Courts et denses : ils servent à reprendre le travail et à rédiger, pas à être publiés.

## cadrage.md

```markdown
# Cadrage : <sujet>
Date : AAAA-MM-JJ · Type : informatif | comparatif · Statut : proposé | validé

## Mot-clé
- Focus keyword : …
- Données Semrush (source : Tom, date) : volume …, KD …, mots-clés associés …
- Intention : …
- Décision : GO | GO avec angle | à creuser | à éviter, et pourquoi

## SERP et angle
- Positions 1 à 3 : type de contenu, fraîcheur
- Ce qui est mal couvert : …
- Angle différenciant retenu : …

## Champ sémantique
- Thème A : variantes …
- À garder pour un autre article (anti-cannibalisation) : …

## Pistes de FAQ (angles, pas encore les questions finales)
- …

## Snippet visé
- Format et condition, ou « aucune opportunité »

## Liens internes candidats (MAILLAGE.md)
- URL, où et pourquoi

## Comparatif uniquement : profil et critères
- Profil acheteur : …
- Non négociables : …
- Différenciants : …
- Contre-indiqués : …
- Contraintes commerciales : …

## Décisions de Tom
- …
```
