## Règles de maillage interne à appliquer

- **Harnais** → toujours pointer vers le guide `/equipement/harnais-randonnee-chien/` en premier, puis vers le comparatif le plus pertinent selon le profil évoqué (grand chien, petit chien, trail, polyvalent).
- **Hydratation / eau** → pointer vers `/sante-bien-etre/hydratation-chien-randonnee/` pour le conseil santé, et vers le guide de choix `/equipement/gourde-gamelle-poche-eau-chien-comment-choisir/` pour l'équipement.
- **Chaleur / été** → pointer vers `/sante-bien-etre/randonner-chien-chaleur-ete/` et croiser avec l'hydratation.
- **Laisse vs harnais** → l'article `/sante-bien-etre/randonner-chien-laisse-collier-dangereux/` est la référence pour justifier le choix du harnais ; le lier depuis tous les articles qui parlent d'équipement.
- **Distance / endurance** → pointer vers `/avant-de-partir/distance-chien-randonnee/`.
- **Zones autorisées / législation** → pointer vers `/avant-de-partir/legislation-zones-autorisees/`.
- **Chiots** → pointer vers `/avant-de-partir/randonnee-chiot/` dès qu'on évoque l'âge ou la croissance.
- **Première randonnée / débutants** → pointer vers `/avant-de-partir/premiere-randonnee-avec-son-chien/`.
- Privilégier les liens contextuels dans le corps du texte (ancres descriptives) plutôt qu'en liste en bas d'article.
- Ne pas sur-mailler : 3 à 5 liens internes par article est suffisant.
